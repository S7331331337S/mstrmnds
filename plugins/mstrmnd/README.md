# mstrmnd

mstrmnd is a portable intelligence layer for agentic systems.

It positions intelligence between vision and execution, giving agents a consistent operating loop for context, memory, planning, orchestration, execution, evaluation, and learning.

## Core focus

- portable, model-agnostic intelligence workflows
- scoped context and persistent memory
- orchestration and agent execution standards
- policy, review, and approval-aware operations
- MCP-based integration with the broader mstrmnd-core runtime

## Included

- `rules/`: doctrine-aligned operating standards and review checkpoints
- `skills/mstrmnd-core/`: guidance for building and extending the intelligence layer
- `agents/mstrmnd-architect.md`: architecture-focused agent for portable intelligence systems
- `commands/sync-runtime-context.md`: command for aligning local plugin context with mstrmnd-core runtime context
- `hooks/hooks.json`: lightweight automation hooks
- `scripts/`: hook scripts
- `mcp.json`: MCP server config for connecting to mstrmnd-core
